# 🛠️ Windows Legacy & Modern Essentials Pack
Сборка проверенных драйверов, библиотек и софта для настройки Windows XP, 7 и 11.

## 🌟 Особенности проекта
* **Личная проверка:** Каждый драйвер и установщик протестирован вручную.
* **Автоматизация:** Для Windows 11 добавлен `.bat` скрипт для тихой установки.
* **Ретро-интернет:** Включены MyPal и свежие корневые сертификаты для выхода в сеть с XP.

## 📦 Состав папок
### [Windows XP]
* **Браузер:** MyPal (современный веб на старом ядре).
* **Библиотеки:** DirectX (июнь 2010), .NET Framework 3.5, Visual C++.
* **Система:** Корневые сертификаты (fix HTTPS), кодеки K-Lite.

### [Windows 7 / 11]
* **Оптимизация:** Скрипт Chris Titus Tech (winutil).
* **Утилиты:** Winaero Tweaker, 7-Zip, OpenAL.
* **Библиотеки:** Visual C++ All-in-One (декабрь 2025).
