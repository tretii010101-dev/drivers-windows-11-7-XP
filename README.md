# 🛠️ Инструкция по настройке систем (XP / 7 / 11)

В данном репозитории представлена подробная инструкция по правильной последовательности установки драйверов, библиотек и системных компонентов. Соблюдение этого порядка гарантирует стабильную работу системы без ошибок.
### 🟦 Windows 98 SE (Порядок «оживления» системы)

Windows 98 SE требует строгого порядка установки компонентов для корректной работы базовых функций, распознавания накопителей и интернета.

**1. Этап 1: Фундамент (Драйверы)**
*   **Чипсет:** Установите в первую очередь. Запустите `infinst_enu-6301007.exe` (для чипсетов Intel) или пакет `VIA Hyperion 4in1 v4.53v` (для плат VIA). Без этого не заработает AGP-порт видеокарты и быстрый режим дисков.
*   **USB Flash Driver:** Установите пакет `Nusb.ver.3.3.Russian.rar`. Это необходимо для того, чтобы система автоматически определяла любые современные флешки в формате FAT32.

**2. Этап 2: Системные библиотеки**
*   **DirectX:** Распакуйте `directx_nov2007_redist.exe` в любую папку и запустите `DXSETUP.exe` внутри неё. Это финальный релиз DirectX 9.0c, способный работать на ядре Windows 9x.
*   **Архиватор:** Установите `wrar393ru.exe`. Классическая 32-битная версия WinRAR необходима для распаковки модов, софта и других драйверов прямо внутри системы.

**3. Этап 3: Софт и Сеть**
*   **RetroZilla:** Ваш основной браузер для выхода в интернет. Перенесите папку на диск `C:\` и создайте ярлык на рабочий стол. Он поддерживает протоколы TLS 1.3, что позволяет открывать современные сайты.

## 🟦 Windows XP (Порядок «оживления» системы)

Windows XP требует строгого порядка установки компонентов для корректной работы современного софта и интернета.

1.  **Этап 1: Фундамент (Драйверы)**
    *   **GPU Driver:** Установите в первую очередь. 
    *   *Важно:* Если вы используете виртуальную машину (VirtualBox/VMware), устанавливайте Guest Additions только в **Safe Mode** (Безопасный режим) с отмеченным пунктом **"Direct3D"**, иначе 3D-ускорение не заработает.
    *   **Root-R1.crt:** Установите сертификат в хранилище «Доверенные корневые центры сертификации». Это необходимо для исправления ошибок HTTPS и доступа к современным сайтам.

2.  **Этап 2: Системные библиотеки**
    *   **DirectX:** Распакуйте `DirectX_Jun2010_redist.exe` в любую папку и запустите `DXSETUP.exe` внутри неё.
    *   **Visual C++:** Установите все три версии `vcredist_x86` по очереди (от 2005 к 2010).
    *   **OpenAL:** Установите `oalinst.exe`. Это критично для звука во многих играх (например, S.T.A.L.K.E.R.).
    *   **.NET Framework:** Установите версию 3.5 для работы лаунчеров и модов.

3.  **Этап 3: Софт и Сеть**
    *   **K-Lite Codec Pack:** Необходим для работы видео и катсцен в играх.
    *   **Mypal:** Ваш основной браузер. Перенесите папку на диск `C:\` и создайте ярлык на рабочий стол.

## 🟩 Windows 7 (Оптимизация и стабильность)

1.  **Visual C++ All-in-One:** Установите этот пакет первым, чтобы закрыть вопросы с отсутствующими DLL-файлами.
2.  **DirectX & PhysX:** Установите июньский дистрибутив DirectX и PhysX для корректной работы физики и графики в играх.
3.  **Браузер:** Используйте MyPal или актуальные версии поддерживаемых браузеров.

## ⬜ Windows 11 (Автоматизация и чистка)

Для Windows 11 важно соблюдать последовательность между скриптами и установкой графических библиотек.

1.  **Шаг 1: Авто-установка:** Запустите файл `INSTALL_ALL.bat` от имени Администратора. Скрипт установит базовый набор библиотек и архиватор.
2.  **Шаг 2: Графика (Критично):** **После** завершения работы `.bat` файла обязательно установите `directx_Jun2010_redist.exe`. Распакуйте его и запустите `DXSETUP.exe`. Это обеспечит совместимость со старыми играми.
3.  **Шаг 3: Оптимизация:** Запустите `winutil.ps1` через PowerShell (от имени Администратора). Этот инструмент позволит в один клик удалить телеметрию и лишние службы.
4.  **Шаг 4: Тонкая настройка:** Используйте `Winaero Tweaker` для настройки интерфейса и контекстного меню под свой вкус.
